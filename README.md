# # Excel Assignment 2 – Data Cleaning and Transformation

## 📌 Overview

This project demonstrates data cleaning and transformation techniques using Microsoft Excel.

The dataset contains product information such as product ID, manufacturing date, country code, product name, brand, price, quantity, and category.

## 🛠️ Tools Used

- Microsoft Excel
- Excel formulas
- Data Cleaning
- Data Transformation
- Conditional Formatting

## 📊 Data Cleaning & Transformation

The following tasks were performed:

- Extracted the **Manufacturing Date** from the Product ID.
- Extracted the **Country Code** from the Product ID.
- Separated the Product ID into required columns.
- Standardized product names and category names.
- Combined **Product Name** and **Brand Name** into a **Product Brand** column.
- Removed duplicate records.
- Filled missing price values using the **median price**.
- Calculated the median product price.
- Applied currency formatting to the Price column.
- Added data bars to visualize product prices.
- Cleaned inconsistent data entries.
